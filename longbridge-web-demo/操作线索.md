# Longbridge Web 原型 · 全量操作线索

按"页面区域 → 触发动作 → 系统反馈"组织,涵盖所有可点 / 可输入 / 可触发的路径。
配合本地 `python3 -m http.server 8000` + 浏览器开启 `http://localhost:8000` 使用。

---

## 0. 场景切换(控制台)

打开浏览器 DevTools console,任何时候都可输入以下命令切换全局场景。三个场景对应不同的持仓 / 时间线 / AI 工作台状态。

| 命令 | 场景 | 表现 |
|------|------|------|
| `setS('active')` | 活跃日 | 持仓 +1.45%,时间线 4 条未读(含 AMZN Signal),AI 工作台多任务运行 |
| `setS('calm')` | 平静日 | 持仓 +0.17%,时间线只有 1 条未读 → 触发空态绿卡「过去 X 小时内无重大变化」 |
| `setS('down')` | 下跌日 | 持仓 -2.72%,时间线密集异动/预警,AI 工作台预警态 + 紧急分析 |

每次切换会重渲染首页,详情列 / chat 列保留。

## 3. 首页 · 进行中的任务(AI 工作台)

横向卡片列表,每张卡可:

| 操作 | 反馈 |
|------|------|
| 点击卡片 | 展开 / 收起详情(`toggleAwDetail`),底部出现描述 + KV 表 + 内嵌动作按钮 |

**卡片来源**(按渲染顺序):
1. 「Move forward」激活后的 `activeTradePlanCards`(显示在最左,squeeze-in 动效)

3. `dynamicAWCards`(Build Trade Plan 触发后的动态任务)
4. `awState[sc].tasks`(AI 长期任务)
5. `awState[sc].strategies`(活跃策略)
6. `awState[sc].orders`(长期订单)

## 7. Signal 详情 · 三按钮 Trade Plan 流程

点 `Draft trade plan` 后,chat 流式生成 Trade Plan 卡片,末尾有 3 个 ✦ 按钮:

### 7.1 ✦ Move forward with this trade plan(`moveForwardTradePlan(tk)`)

1. AI 工作台「进行中的任务」**最左侧插入新卡**,初始状态「激活中」(亮绿 + 脉动),其他卡 squeeze-in 向右挤
2. chat 出现确认气泡:`Sure! Your trade plan is now active...`
3. 紧接出现富气泡:✓ Order submitted + 标的 / 方向 / 数量 / TP / SL + AI 实时监控 + 两个动作按钮
4. **气泡出现的瞬间**,AI 工作台卡片状态从「激活中」自动切换为「运行中」(深绿稳)

### 7.2 ✦ Increase target position

1. chat 出现 AI 建议气泡(目标仓位从 10% → 15%,带 KV 表)
2. 末尾两个 chip:`接受调整` / `保持原计划`

### 7.3 ✦ Tell me more about trade plan

chat 流式输出多段 Trade Plan 概念解释(适合学习场景,不触发交易)。

## 8. 底部全局 AI 输入框

| 状态 | 触发 | 视觉 |
|------|------|------|
| 静默 | 空闲 | 灰边框 |
| 聚焦 | 点击输入框 | 青色边框 + 上方浮出 5 个快速意图 chip |
| 实时形变 | 命中关键词 | 边框变青 + 渐变背景 + 脉动绿点(主区已切换为动态视图) |

### 8.1 5 个快速意图 chip(聚焦后浮出)

- 分析持仓风险
- NVDA 能追吗
- 对比 NVDA 和 AMD
- 帮我建一个 NVDA Trade Plan
- 今天为什么跌了

点击 chip → `tryIntent(text)` → 输入框填字符 → 触发 `handleLiveInput` → 主区动态布局。

### 8.2 5 类动态视图触发关键词(`classifyIntent`)

| 视图 | 正则 | 示例输入 |
|------|------|---------|
| `dyn-compare` | 对比 / 比较 / vs / 哪个好 / 应该选 | `对比 NVDA 和 AMD` |
| `dyn-tradeplan` | trade plan / 建单 / 交易计划 / 止损 / 期权 / 加仓方案 / 建仓 | `帮我建 NVDA 期权` |
| `dyn-attribution` | 为什么跌 / 为什么亏 / 亏损来自 / 归因 / 影响多大 / 怎么回事 | `今天为什么跌了` |
| `dyn-research` | 已知 ticker(NVDA/AAPL/GOOG/TSM/AMD/META/MSFT/AMZN/TSLA/BABA) | `NVDA` / `看看 AAPL` |
| `dyn-risk` | 风险 / 持仓 / 我的资产 / 我的仓位 / 组合 | `分析持仓风险` |

**实时反馈**(无需回车):每输入一个字符就重判定,主区即时切换 / 重组。删空输入框 → `exitDynamic()` 回到 `previousView`。

### 8.3 LongbridgeAI 富回复触发(回车后)

输入需同时包含 ticker + 追问意图词(`能追/追高/能买/能上车/可以买/该买/要不要买/值得买/该追`),回车后 chat 流式输出 7 段富回复:

1. **检索您的相关记忆**(折叠,默认收起)→ 展开看到日期 chip
2. **关键数据检索**(折叠)→ 展开看到 4 个工具调用 chip
3. **免责声明 + 引言段**
4. **§1 技术面与资金情绪**(标题 + 段落 + 2 条 bullet,含 `longbridge.com` 引用 chip)
5. **§2 估值水平**
6. **§3 产业基本面**
7. **§情景推演与应对思路**(情景 A/B/C)
8. **来源汇总 + 反馈图标 + 4 条 ✦ 后续追问按钮**

### 8.4 回车不命中富回复触发但命中意图

走通用响应:chat 出现简短确认气泡(`持仓风险布局已展示` / `NVDA 和 AMD 对比已展示` 等),主区动态视图保持。

## 9. 5 类动态视图详情

### 9.1 类型 1 · 风险审视(`renderDynRisk`)

**触发**:`分析持仓风险` / `我的仓位` / `组合`

**模块**:
- KPI 行(总资产 / 持仓数 / vs SPY)+ 风险评分仪表盘(72 分,4 因子)
- 行业分布柱状图 + 集中度 Top 5
- 通栏持仓明细表(每行可点开标的详情)
- 相关订单 + 相关策略
- AI 总结段落

**底部按钮**:再平衡 / 对比 / 止损 / 导出 PDF

### 9.2 类型 2 · 标的研究(`renderDynResearch`)

**触发**:任意 ticker 单词 / `NVDA 能追吗` / `看看 AAPL`

**12 模块**:
1. AI 综合分析 hero(顶部薄荷绿大卡 + 4 chip 卡)
2. Quant Ratings 5 因子(全宽,字母评级)
3. 行情头 + 走势图
4. 估值因子分解(5 行 P/E / P/S / PEG / EV-EBITDA / P/B)
5. 基本面 + 技术面
6. 季度营收/EPS bars(6 季度,预期透明)
7. 分析师评级分布(目标价 + 上行空间 + 五档)
8. 同行业对比表(全宽,NVDA 行高亮)
9. 估值历史(5Y 高/低/中位/分位)
10. 业绩预期(FY25 共识)
11. 相关事件 + 持仓 + 相关策略
12. AI 深度分析

**底部按钮**:建 Trade Plan / 和 AMD 对比 / 设价格提醒 / 查看回测

### 9.3 类型 3 · 对比决策(`renderDynCompare`)

**触发**:`对比 NVDA 和 AMD`

**模块**:
- 标的 A / B 数据卡(并排,6 行 KV)
- **Factor Grades 高亮表**(7 行:估值/成长/盈利/动量/EPS 修正 + 持仓占比 + Signal 评级,差异行带高亮 + 优势 chip)
- 总结 chip 行(NVDA 领先 / AMD 占优 / 差距收窄)
- AI 观点段落

**底部按钮**:加自选 / 建 Trade Plan / 查看供应链重叠 / 两个都买怎么分配

### 9.4 类型 4 · 策略构建(`renderDynTradePlan`)· 参数实时编辑

**触发**:`帮我建 Trade Plan` / `建仓 NVDA` / `期权方案`

**左列(可编辑)**:
| 控件 | 类型 | 选项 |
|------|------|------|
| 策略类型 | radio | Long Call / Long Put / Bull Call Spread / Covered Call |
| 行权价 | 数字框 | $145(默认),100-200,step 1 |
| 到期 | select | 14/28/42/56/77 天 5 档 |
| 合约数 | 步进器 | 1-20,− [1] + |

**右列(只读,实时)**:
- 期权金 / 净支出
- 盈亏平衡价
- 最大亏损
- 占组合 %
- +10% 涨预期收益
- IRR(到期假设)
- 价格区间盈亏 bar

**修改任一参数 → 右列 6 个数字 0.4s 绿色闪烁更新 + bar 重画**(`tpRecalc`)。

**通栏**:AI 推理 + 三栏(✓ Strategy fit / ⚙ Execution rules / ⚠ Risk warning)

**底部按钮**:下单这个 Plan(走 7.1 完整激活流程)/ 调整参数 / 另存为策略 / 查看历史回测

### 9.5 类型 5 · 归因诊断(`renderDynAttribution`)

**触发**:`今天为什么跌了` / `亏损来自`

**模块**:
- 今日盈亏瀑布图(8 标的横向条形,亏损金额从大到小)
- 宏观事件卡(3 项)
- 通栏受影响持仓排序表(每行可点开)
- AI 归因分析段落(系统性 vs 个股,历史回撤参考)

**底部按钮**:分析持仓风险 / 哪些仓位应该减 / 执行 AAPL 止损 / 下跌评估

### 9.6 5 视图相互流转(链路示例)

每个视图底部按钮通过 `tryIntent(text)` 自动填充输入框 → 触发下一个视图:

- **风险审视** → 「对比 NVDA 和 AMD」 → **对比决策** → 「建 AMD Trade Plan」 → **策略构建** → 「下单」
- **归因诊断** → 「执行 AAPL 止损」 → **策略构建**
- **标的研究** → 「分析持仓风险」 → **风险审视** → 「生成再平衡」

Chat 富回复底部的 ✦ 后续追问按钮也是同一条流转路径(走 `tryIntent`)。
